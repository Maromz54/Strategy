# Strategy

מאגר לבניית אסטרטגיית מסחר עבור בוט הטריידינג.

האסטרטגיה נלמדת מקורס וידאו: המשתמש מספק כתוביות, סיכומים וסטי שאלות,
ומהם נגזר קובץ אסטרטגיה שהמערכת יכולה לצרוך.

## מבנה

| נתיב | תוכן |
|---|---|
| `STRATEGY.md` | מסמך האסטרטגיה החי — מתעדכן אחרי כל שיעור. מקור האמת. |
| `transcripts/` | כתוביות גולמיות של סרטוני הקורס |
| `notes/` | הערות מעובדות לכל שיעור (`NN-נושא.md`) |
| `qa/` | סטי השאלות של המשתמש + התשובות שלי, לאימות ההבנה |
| `spec/` | הגרסה המכונתית של האסטרטגיה (ייווצר בשלב הגזירה) |

## תהליך העבודה

לכל שיעור:

1. קריאת הכתוביות מ-`transcripts/`
2. כתיבת `notes/NN-נושא.md` — תקציר, מונחים חדשים, וחוקים בניסוח שניתן לקודד
3. **סימון פערים ויזואליים** — רגעים שבהם המרצה מצביע על הגרף ("תראו פה",
   "הרמה הזאת") שהטקסט לבדו לא מכסה. אלה מרוכזים בסוף כל קובץ הערות
   כבקשות לצילום מסך.
4. מענה על סט השאלות ב-`qa/`, ותיקון מה שפוספס
5. עדכון `STRATEGY.md` וקומיט

## מגבלה ידועה

התמלול הקולי והורדת וידאו חסומים במדיניות הרשת של סביבת ההרצה
(GitHub ו-PyPI פתוחים; YouTube, Groq, OpenAI, HuggingFace חסומים).
לכן הכתוביות מסופקות ידנית, ופערים ויזואליים נסגרים בצילומי מסך לפי בקשה.
