# Strategy

מאגר לבניית אסטרטגיית מסחר עבור בוט הטריידינג.

התהליך: המשתמש מלמד את האסטרטגיה דרך סרטונים, סטי שאלות וסיכומים.
כל שיעור נצבר כאן, ובסוף נגזר ממנו קובץ אסטרטגיה שהמערכת יכולה לצרוך.

## מבנה

| נתיב | תוכן |
|---|---|
| `STRATEGY.md` | מסמך האסטרטגיה החי — מתעדכן אחרי כל שיעור. מקור האמת. |
| `notes/` | הערות גולמיות לכל סרטון (`NN-נושא.md`) |
| `qa/` | סטי השאלות של המשתמש + התשובות שלי, לאימות ההבנה |
| `spec/` | הגרסה המכונתית של האסטרטגיה (ייווצר בשלב הגזירה) |

## סטטוס

- [ ] שלב 1 — למידה: צפייה בסרטונים, הערות, מענה על שאלות
- [ ] שלב 2 — גיבוש: `STRATEGY.md` מלא וחד־משמעי (חוקים ניתנים לקידוד)
- [ ] שלב 3 — גזירה: קובץ אסטרטגיה בפורמט שהמערכת קוראת
- [ ] שלב 4 — אימות: בקטסט / הרצה מול הבוט
