# שיעור 05 — Reducing Candlestick Ambiguity

מקור: `transcripts/L005_Reducing_Candlestick_Ambiguity.json` · global 79 · שיעור קצר

## הבעיה

בנר בודד יש ארבעה מחירים — `open`, `high`, `low`, `close` — אבל **אין דרך לדעת אם השיא
נוצר לפני השפל או אחריו** בלי לרדת לטווח זמן נמוך יותר.

והירידה לטווח זמן נמוך יוצרת **פרדוקס**:

> "switching time frames can generate paradoxical situations where the increase in market
> information leads to a **worse** analysis."

זה פרדוקס כי יותר מידע *אמור* להוביל לניתוח טוב יותר. (מאושר במבחן, שיעור 5 שאלה 1.)

## הפתרון — Path of Least Resistance

במקום להחליף טווח זמן, **מניחים** שהנר נוצר לפי מסלול ההתנגדות הנמוכה ביותר: המחיר
מנווט בין ארבעת המחירים בצורה היעילה ביותר.

```
Open  →  Nearest Extreme  →  Opposite Extreme  →  Close
```

כלומר: המחיר הולך קודם לאקסטרם **הקרוב ביותר ל-open**, משם לאקסטרם הנגדי, ומשם לסגירה.

**דוגמה מהשיעור (01:18):** נר ירוק שבו ה-open קרוב יותר ל-high מאשר ל-low. המסלול
המשוער: `open → high → low → close`.

השיעור מדגיש שזה **לא תמיד** נכון, אבל זה מה שקורה **רוב הזמן**, כי זהו מסלול ההתנגדות
הנמוכה ביותר.

> מלכודת מבחן (שיעור 5, שאלה 2): "המחיר **פחות** סביר שיעקוב אחר מסלול ההתנגדות
> הנמוכה" — **שגוי**. הוא **יותר** סביר.

## המקרה החריג — הנר הבלתי-מוכרע

כאשר `open == close` והגוף ממורכז בדיוק, שני האקסטרמים נמצאים **במרחק זהה** מה-open.
אז אין דרך להחיל את המנגנון — אין "אקסטרם קרוב יותר".

השיעור אומר במפורש שזה **חלק מהסיבה** שנר בצורה כזו (doji ממורכז) מתפרש כ**בלתי-מוכרע**
(`indecisive`). כלומר חוסר ההכרעה אינו רק מראה חיצוני — גם מסלול ההיווצרות עצמו מעורפל.

בתיאור המסך (01:31) מוצגים שני מסלולים אפשריים זה לצד זה, עם הכיתוב `Indecisive path`.

## חוק ניתן לקידוד

```python
def formation_path(o, h, l, c):
    """מסלול ההיווצרות המשוער של הנר, לפי path of least resistance."""
    d_high, d_low = abs(h - o), abs(o - l)
    if   d_high < d_low: return ("open", "high", "low",  "close")
    elif d_low  < d_high: return ("open", "low",  "high", "close")
    else:                 return None            # בלתי-מוכרע
```

**למה זה חשוב לבוט:** זה נותן סדר זמנים משוער בתוך הנר בלי למשוך נתוני טווח זמן נמוך.
כל חישוב שתלוי בשאלה "מה קרה קודם" — מימוש סטופ, נגיעה ברמה, סדר אירועים — יכול
להישען על זה מסדרה בודדת.

**סייג שחייב להירשם בקוד:** זו **הנחה הסתברותית, לא עובדה.** בבקטסט, נר שבו הסטופ והיעד
נמצאים שניהם בתוך הטווח יוכרע לפי ההנחה הזו, וזה מקור ידוע לאופטימיות יתר. צריך למדוד
כמה עסקאות תלויות בהנחה הזו ולדווח עליהן בנפרד.
