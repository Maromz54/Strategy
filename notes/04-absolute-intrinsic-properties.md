# שיעור 04 — Absolute Intrinsic Properties

**השיעור הראשון עם תוכן ניתן לקידוד במלואו.** שש תכונות של נר בודד בבידוד.

## 1. Bias / Sentiment (הטיה/סנטימנט)

נקבע לפי מיקום ה-close ביחס ל-open.

```
close > open  →  bullish bias
close < open  →  bearish bias
```

**הנימוק המהותי** (ולא רק ההגדרה): אם מסכמים את כל התנודות כלפי מעלה בתוך הנר ואת כל
התנודות כלפי מטה, **ההפרש בין הסכומים שווה בדיוק לגוף הנר**.

```
Σ(upward moves) − Σ(downward moves) = body
```

לכן הגוף הוא שמראה מי היה חזק יותר בזמן היווצרות הנר. נר ירוק = הקונים גברו על המוכרים
במידה כלשהי.

**מגבלה מפורשת:** ה-bias **מכייל** (qualifies) את הנר — בולי או ברי — אבל **לא מכמת**
אותו. אי אפשר לדעת ממנו *כמה*.

> מלכודת מבחן (שיעור 4, שאלה 2): הניסוח ההפוך — "Bias מכמת ו-Body Size מכייל" — **שגוי**.
> `bias` מכייל, `body size` מכמת.

## 2. Body Size (גודל הגוף)

```
body_size = |close − open|
```

זה מה ש**מכמת** את ה-bias. גדול יותר = בולי/ברי יותר.

השיעור מציין שהעין האנושית מעריכה גודל גוף אוטומטית ביחס לרוחב הנר, בלי פרמטר אובייקטיבי;
מדידה אובייקטיבית מגיעה בשיעורי ה-relative properties.

## 3. Range (טווח) — מדד ל-volatility

```
range = high − low
```

שונה מ-body size: הטווח כולל את הצללים. ככל שהטווח רחב יותר, ה-volatility גבוה יותר —
נדרשת יותר "אנרגיה" ליצירת נר רחב-טווח.

### מדידה אובייקטיבית — האינדיקטור המותאם

זו הפעם הראשונה בקורס שניתן כלי מדידה מספרי מדויק.

**בנייה** (כפי שנאמר, בפלטפורמת צ'ארטים):
1. הוסף `ATR`, שנה period ל-**1**
2. בלשונית styling — שנה תצוגה ל-**columns**
3. הוסף `Bollinger Bands`, גרור אותו לחלון של ה-ATR
4. שנה את ה-source של ה-BB ל-**ATR**, ואת ה-period ל-**50**
5. בלשונית styling — בטל את הסימון של `lower` ושל `background`

**מה זה בעצם, לצורך קידוד:**

```python
range_t = high_t - low_t          # = ATR(1)
ma      = SMA(range, 50)          # הקו הכתום
sd      = STDEV(range, 50)        # סטיית תקן נעה
upper_2 = ma + 2*sd               # הקו הכחול (ברירת מחדל)
upper_3 = ma + 3*sd               # בהגדרה חלופית, לזיהוי outliers
```

**סיווג:**

| תנאי | סיווג |
|---|---|
| `range < ma` | **narrow range** — מתחת לממוצע |
| `ma ≤ range ≤ upper_2` | **medium range** — מעל הממוצע אך לא קיצוני |
| `range > upper_2` | **wide range** — יותר משתי סטיות תקן |
| `range > upper_3` | **outlier** — טווח קיצוני |

**הערה חשובה מהשיעור:** ל-range, כמו ל-volatility, יש **התנהגות מחזורית**. זה מסומן
כדבר משמעותי לאיתור עסקאות איכותיות בהמשך.

## 4. Shadows (צללים)

```
upper_shadow = high − max(open, close)
lower_shadow = min(open, close) − low
```

**הפרשנות הפוכה לאינטואיציה של רבים:**

| צל | מסמן |
|---|---|
| **upper shadow** | לחץ **מכירה** (selling pressure) |
| **lower shadow** | לחץ **קנייה** (buying pressure) |

**הנימוק:** כדי שצל ייווצר, צד אחד חייב להתקדם ואז הצד הנגדי חייב **להצליח לנטרל** את
התנועה. צל עליון = הקונים הגיעו לראש הטווח, ואז המוכרים הופיעו ודחפו חזרה. לכן הצל
העליון מעיד על נוכחות מוכרים.

> מלכודת מבחן (שיעור 4, שאלה 6): "צל עליון מרמז לחץ בולי וצל תחתון לחץ ברי" — **שגוי**.

הצללים יסומנו בהמשך כמרכיב מרכזי ב: `frequencies`, `dynamic frequency breakouts & stops`,
`fractal manipulations`, `fractal candles`.

## 5. Body% — מדד ל-uncertainty

```
body_pct = body_size / range        # = |close − open| / (high − low)
```

**מודד אי-ודאות:**

| ערך | פירוש |
|---|---|
| `body_pct` נמוך | **אי-ודאות** — גוף קטן, צללים גדולים; המחיר התנודד למעלה ולמטה בלי הטיה ברורה |
| `body_pct` גבוה | **ודאות** — גוף גדול, צללים קטנים; תנועה ישירה ומוטה |

מעבר מנר בעל body% נמוך לנר בעל body% גבוה = מעבר מאי-ודאות לוודאות.

> אישור מבחן (שיעור 4, שאלה 3): volatility נמדד ב-`Range`, uncertainty נמדד ב-`Body%`.

## 6. Shadow Symmetry / Body Position

**שני צדדים של אותו מטבע** (מאושר במבחן, שיעור 4 שאלה 4) — סימטריית הצללים ומיקום הגוף
בתוך הטווח הם אותו מידע.

ה-body% נותן תחושת אי-ודאות אבל **לא אומר כלום על האיזון** בין לחץ קנייה למכירה. זה
התפקיד של התכונה הזו — היא **ממקמת בהקשר** את ה-body%.

| מצב | פירוש |
|---|---|
| body% נמוך + צללים **סימטריים** | אי-ודאות **ואיזון** בין הצדדים |
| body% נמוך + צללים **א-סימטריים** | אי-ודאות **עם נטייה** לאחד הצדדים |
| גוף **נמוך** בטווח (צל עליון ארוך) | אי-ודאות עם **הטיה ברית** |
| גוף **גבוה** בטווח (צל תחתון ארוך) | אי-ודאות עם **הטיה בולית** |

ככל שהא-סימטריה גדולה יותר, כך הנטייה חזקה יותר.

שים לב לעקביות עם סעיף 4: גוף נמוך בטווח ⇒ צל עליון ארוך ⇒ לחץ מכירה ⇒ ברי. ✓

## מפרט קידוד מרוכז

```python
def absolute_intrinsic(o, h, l, c, range_ma50, range_sd50):
    rng  = h - l
    body = abs(c - o)
    return {
        "bias":         "bullish" if c > o else "bearish" if c < o else "neutral",
        "body_size":    body,
        "range":        rng,
        "range_class":  ("outlier" if rng > range_ma50 + 3*range_sd50 else
                         "wide"    if rng > range_ma50 + 2*range_sd50 else
                         "medium"  if rng >= range_ma50 else "narrow"),
        "upper_shadow": h - max(o, c),      # לחץ מכירה
        "lower_shadow": min(o, c) - l,      # לחץ קנייה
        "body_pct":     body / rng if rng else 0.0,   # ↓ = אי-ודאות
        # א-סימטריה: חיובי ⇒ צל תחתון דומיננטי ⇒ הטיה בולית
        "shadow_asym":  ((min(o,c) - l) - (h - max(o,c))) / rng if rng else 0.0,
    }
```

## פערים פתוחים

- **אין ספים מספריים ל-body%.** מה נחשב "נמוך"? מה "גבוה"? השיעור מדבר איכותית בלבד
  ומזכיר ש"אפשר להעריך את זה אובייקטיבית דרך אינדיקטורים" — בלי לפרט אילו. → לחפש
  בשיעורים 7-8 (relative intrinsic properties).
- **אין סף ל-shadow asymmetry.** מתי א-סימטריה "גדולה"?
- ה-`range` מסווג סטטיסטית מול 50 תקופות. **body% לא מקבל טיפול סטטיסטי מקביל** —
  לבדוק אם זה מגיע בהמשך.
